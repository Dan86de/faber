# Glossary

> One term per line: the word, then what it means here. Agents use these words and no synonyms.

- **slice**: one vertical piece of a feature, built and proven in one fresh session.
- **afk / hitl**: a slice an agent may finish alone, or one that waits for a person.
- **trailer**: the `Slice:` or `Slice-Pending:` line in a commit, the only record of progress.
- **adapter**: the code that starts one harness headless with a skill and its arguments.
